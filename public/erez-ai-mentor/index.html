רקע ומטרה

המטרה היא לבנות בפועל את המערכות שהוגדרו, תוך כדי רכישת יכולת עצמאית לעבודה עם Claude Code וכלי AI נוספים.

התהליך אינו בנוי כקורס או כסדרת שיעורים, אלא כליווי טכנולוגי שוטף סביב פרויקטים אמיתיים.

ארז מבצע את עיקר עבודת הפיתוח בפועל, ושלומי משמש כ-CTO של הפרויקט — מוביל את הצד הטכנולוגי, מגדיר את הדרך, מעביר את הידע הנדרש, מסייע בקבלת החלטות ובפתרון בעיות, ודואג שלארז יהיו בכל שלב הכלים וההנחיות הנדרשים כדי להתקדם.

כך הלמידה מתבצעת תוך כדי עשייה אמיתית, על המערכות שארז ממילא מעוניין לבנות.

מבנה הליווי

  • פגישת סנכרון שבועית קבועה לצורך מעבר על ההתקדמות, למידה, קבלת החלטות ותכנון המשך.
  • ליווי שוטף במהלך השבוע באמצעות WhatsApp ושיחות קצרות לפי הצורך והזמינות.
  • סיוע Hands-on כאשר נתקלים בבעיה טכנולוגית שדורשת התערבות.

אתר ליווי ייעודי

אתר ליווי ייעודי, שייבנה עבור התהליך וישמש כמרכז העבודה המשותף לאורך הפרויקט.

באתר ירוכזו באופן שוטף המשימות, חומרי הלמידה, הסברים, החלטות טכנולוגיות, הנחיות עבודה, קישורים וכל מידע נוסף שנדרש לצורך ההתקדמות. במידת הצורך יועלו גם הנחיות ו-Prompts מוכנים לעבודה מול Claude Code, כך שלאחר שיחה או החלטה על כיוון מסוים, ארז יקבל בצורה מסודרת את מה שנדרש ממנו לבצע. האתר יתעדכן בהתאם להתקדמות ולנושאים שעולים בפועל במהלך העבודה.

המטרה היא שמעבר לפגישה השבועית, יהיה לארז באופן יומיומי מקום אחד שבו ברור מה עושים עכשיו, איך עושים את זה ומה צריך לדעת כדי להתקדם.

אין מכסת שעות או מספר מוגדר של מפגשים — הליווי הוא חודשי וממוקד בהתקדמות הפרויקט.

חלוקת אחריות

שלומי
  • אחריות והובלה של הצד הטכנולוגי.
  • תכנון הארכיטקטורה ובחירת ה-Stack והכלים המתאימים.
  • פירוק העבודה לשלבים והגדרת סדרי עדיפויות.
  • העברת הידע והחומר הלימודי הנדרש לאורך הדרך, בהתאם לפרויקט ולאתגרים שעולים בפועל.
  • לימוד והכוונה לעבודה נכונה ואפקטיבית עם Claude Code וכלי AI.
  • הכנת הנחיות עבודה ו-Prompts ל-Claude Code בהתאם לצורך.
  • ניהול ועדכון אתר הליווי כך שירכז את הידע, המשימות וההנחיות הנדרשים להתקדמות.
  • Code Review, פתרון בעיות וקבלת החלטות טכנולוגיות.
  • תכנון אינטגרציות, APIs, בסיסי נתונים, תשתיות ו-AI בהתאם לצורך.
  • ליווי בתהליך ההגעה למוצר עובד ו-Production.
ארז
  • הגדרת הצרכים העסקיים והפונקציונליים.
  • ביצוע עיקר עבודת הפיתוח בפועל באמצעות Claude Code והכלים שיוגדרו.
  • מעבר על חומרי הליווי וביצוע המשימות שיוגדרו.
  • בדיקות ופידבק שוטף.
  • התקדמות בין הפגישות בהתאם לתוכנית העבודה.

המטרה היא שארז לא רק יתקדם בבניית המערכות, אלא ירכוש תוך כדי התהליך יכולת אמיתית להוביל ולנהל תהליך פיתוח באמצעות AI.

תחומי הלמידה והעבודה

הלמידה אינה בנויה כסילבוס קשיח, אלא משתלבת בהתאם לאתגרים שעולים במהלך העבודה:

עבודה נכונה ואפקטיבית עם Claude Code כלי AI משלימים תכנון ופיתוח אפליקציות Web עבודה עם APIs ו-Webhooks בסיסי נתונים ו-Backend Authentication והרשאות שימוש ב-LLMs ושירותי AI בניית Agents ואוטומציות אינטגרציות עם שירותים חיצוניים Deployment, Hosting וסביבות Production הבנת עלויות AI, APIs, Tokens ותשתיות בחירת הכלי והגישה הנכונים לכל משימה

הפרויקטים לעבודה מעשית

העבודה תתבסס על שני הפרויקטים שהוגדרו בהצעה המקורית:

1 מערכת שיווק וניהול משרד/קליניקה להשכרה לפי שעה.
2 מערכת ניהול לקוחות ליועצת זוגיות (מיכל).

אלו ישמשו כבסיס ללמידה ולעבודה המעשית לאורך התהליך.

מטבע הדברים, בפרויקטים אמיתיים יהיו דברים שיהיו פשוטים ומהירים לביצוע, דברים שיהיו מורכבים יותר, ודברים שעשויים להיות תלויים בשירותי צד ג', APIs, הרשאות, עלויות או מגבלות טכנולוגיות אחרות. ייתכנו גם דרישות שנגלה שלא נכון או שלא ניתן לממש בדיוק בצורה שבה תוכננו מלכתחילה.

חלק מרכזי מהליווי הוא לדעת להתמודד בדיוק עם המצבים האלה: להבין את הבעיה, לבדוק מה אפשרי, לבחון חלופות, להבין את המשמעויות ולקבל החלטה טכנולוגית נכונה.

מטרת הלמידה היא להגיע למצב שבו ארז מסוגל לנהל את Claude Code בצורה אפקטיבית ולקיים מולו שיח טכנולוגי מקצועי ומושכל — להבין את האפשרויות שהוא מציע, לאתגר אותן כשצריך ולקבל בעזרתו החלטות נכונות לאורך תהליך הפיתוח.

תמחור

10,000 ₪ + מע"מ לחודש
הערכת משך ראשונית: 2–3 חודשים, בהתאם לקצב העבודה ולהיקף שנבחר לממש

התמחור הוא עבור ליווי CTO בעצימות נמוכה, כאשר ארז מבצע את עיקר עבודת הפיתוח ושלומי מספק את ההובלה, הידע והמעטפת הטכנולוגית הנדרשת להתקדמות.

אין ספירת שעות ואין חיוב לפי מספר פגישות במסגרת הליווי השוטף.

תנאי תשלום

מקדמה 30%

בתחילת החודש הראשון תשולם מקדמה בגובה 30% מהתשלום החודשי.

ליווי כזה דורש ממני להיכנס לפרויקט, לפנות עבורו מקום ולהתחייב להיות זמין להתקדמות שלו גם מעבר לפגישה השבועית. לכן המקדמה היא מבחינתי דמי רצינות ושריון של הליווי. היא כמובן חלק מהתשלום של החודש הראשון ולא תשלום נוסף.

יתרה

בסוף כל חודש תוצא חשבונית עבור יתרת התשלום הרלוונטית, לתשלום עד ל-10 בחודש העוקב.

תנאים כלליים

  • בסיום כל חודש קיימת נקודת בדיקה ויציאה — כל צד רשאי לסיים את ההתקשרות ללא התחייבות לחודש נוסף.
  • עלויות תשתית, אחסון, דומיינים, שירותי AI, APIs ושירותי צד ג' יהיו על חשבון ארז.
  • הקוד והאפליקציות שיפותחו במסגרת הפרויקט שייכים לארז.
  • אין התחייבות לתקופת מינימום.
  • קצב ההתקדמות תלוי גם בהיקף העבודה שמבוצע על ידי ארז בין הפגישות ובמגבלות או תלויות חיצוניות שעשויות להתגלות במהלך העבודה.
  • הצדדים מתחייבים לשמור בסודיות מידע עסקי וטכנולוגי שנחשף במסגרת העבודה.
  • ניתן לצרף את יובל ו/או מיכל לפגישות נקודתיות בנושאים הרלוונטיים להם, בתיאום מראש.

עקרון העבודה

ארז הוא הידיים העובדות ובונה את המערכות בפועל. שלומי מספק את הידע, ההכוונה וההובלה הטכנולוגית ודואג שארז יקבל לאורך הדרך את כל מה שהוא צריך כדי להתקדם.
