Mind - connect a computer

המוח השני - חיבור מחשב. את המפתח מוצאים בעמוד, תחת "חיבור מחשב".

For a Claude Code session: Shlomi wants this computer's Claude Code connected to his second brain (shlomiverse.com/mind). He gives you his mind key (starts with mind_). Run in a shell (Node 18+ is needed):

curl -fsSL https://shlomiverse.com/mind/setup/install.mjs -o mind-install.mjs
node mind-install.mjs --key <HIS KEY> --machine "<a short name for this computer, e.g. Laptop>"

In Windows PowerShell 5 write curl.exe, not curl. Then delete mind-install.mjs. Tell him it's done (sessions already open pick it up after a restart). Already set up? Run it without --key: it keeps the key it has.

What it sets up

Mind is Shlomi's own notebook. Since 2026-11-12 a session writes there only when he tells it to - no session tracking, no reports.

  • ~/.mind/ - the key, this computer's name and the CLI (mind.mjs) for sessions without MCP.
  • Removes the old session-tracking hooks from ~/.claude/settings.json if they are there.
  • The mind skill in ~/.claude/skills/mind/ (SKILL.md) - write only when he asks.
  • A short block in ~/.claude/CLAUDE.md with the same rule.
  • The mind MCP server for all projects: https://shlomiverse.com/mind/mcp (HTTP, header Authorization: Bearer <key>).

Run it again any time to update. node mind-install.mjs --uninstall removes it.

Only the MCP server (any MCP client)

claude mcp add --transport http --scope user mind https://shlomiverse.com/mind/mcp --header "Authorization: Bearer <key>"
