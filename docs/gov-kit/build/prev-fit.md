# מענה לשלוש שאלות ביחס לשני התיחורים
>> בהמשך לשיחתנו ולבחינת שני המסמכים, להלן המענה לתפקיד, למבנה הצוות ולעמידה בתנאי הסף וניקוד האיכות.

יפעה, עברתי על התיחור לפיתוח והגירה לענן מבוסס Agentic AI ו-Spec-Driven Development, ועל התיחור להמשך פיתוח מערכת "עולים לענן". המענה להלן מתייחס לשניהם, תוך הבחנה בדרישות הייחודיות של כל אחד.

## 1. התפקיד

אני עונה לתפקיד **מוביל Agentic AI ו-SDD, ארכיטקט ופיתוח**. אני מכסה גם DevOps ב-AWS וב-GCP, וניהול מקצועי של עבודת הפיתוח לאורך ה-SDLC.

אני האדם המוצע לראיון ולביצוע בפועל. לתיחור "עולים לענן" יש התאמת Stack ישירה: Next.js, React, TypeScript, Playwright ו-AWS, לצד ניסיון במערכות פרטיות וציות שבהן רגולציה מתורגמת לכללים ובקרות.

## 2. מבנה הצוות

ליבת הצוות היא בעל מקצוע אחד שאחראי על התמונה הטכנולוגית המלאה, ולצדה מעטפת מצדכם עבור הדרישות המבניות והחוזיות של התיחור.

| תפקיד | מי |
|---|---|
| מוביל Agentic AI ו-SDD | אני |
| ארכיטקט, פיתוח ו-Code Review | אני |
| DevOps וניהול עבודת הפיתוח | אני |
| מנהל פרויקט וממשק חוזי | מצדכם |
| מוקד שירות לפי SLA | מצדכם |
| מפתח גיבוי להמשכיות ולמשימות מקבילות | מצדכם, בהכשרה למתודה |
| QA קבלה ואיש קשר אבטחת מידע | מצדכם, לפי צורך |
| בעלי סיווג מתאים | מצדכם |

היתרון הוא ליבה רזה עם בעלות מקצועית אחת על הארכיטקטורה, הקוד, התשתית והמתודולוגיה, לצד כיסוי מלא של דרישות השירות, ההמשכיות והמסגרת הממשלתית.

## 3. תנאי סף וניקוד איכות

| רכיב | משקל | מה אני מביא |
|---|---|---|
| התרשמות מיכולת | 20% | מעל 20 שנות פיתוח, יותר מ-50 מוצרים שנבנו מאפס, וניסיון מעשי מלא ב-SDLC ובמערכות Web מורכבות. |
| איכות ההצעה ומתודולוגיה | 20% | מסמך מתודולוגיה כתוב ל-Agentic AI לאורך ה-SDLC, כולל Spec, חוקה פרויקטלית, שערי איכות, Code Review ותיעוד עקיבות. |
| התאמה לצורכי המשרד | 30% | התאמה ישירה ל"עולים לענן" ולדרישות Agentic AI, SDD, פיתוח Web, ענן וציות. |
| ראיון | 30% | זהו רכיב חזק עבורי. אוכל להציג את שיטת העבודה, את תהליך הבקרה ואת המעבר מ-Spec לקוד ולבדיקות. |
| שנה ניסיון ב-Agentic AI | תנאי | יותר משנתיים של עבודה עמוקה עם סוכני AI, ארכיטקטורות multi-agent, RAG, זיכרון, כללים דטרמיניסטיים ו-Evals. |
| 2 פרויקטים דומים וממליצים | תנאי | ניתן לבחור יחד שני פרויקטים מהמגזר הפרטי בישראל, ולתאם ממליצים בהתאם לדרישות התיחור. |

::: callout
הניסיון הממשלתי הספציפי, לרבות Nimbus, אזור נחיתה, יה"ב ועבודה במסגרת הספקים, יגיע מצדכם. ברכיבי ה-Agentic, המתודולוגיה והראיון אני יכול להביא מענה למלוא ניקוד האיכות.
:::

## 4. איך אני עובד

אני עובד עם Claude Code כסביבת ההנדסה, כאשר המודלים נצרכים דרך Amazon Bedrock או Vertex AI בחשבון הענן של המשרד, בכפוף לאישורי Nimbus. העבודה מתחילה ב-Spec, עם Requirements, Plan ו-Tasks בעברית קריאה, חוקה פרויקטלית ושערי אישור אנושיים. כל שינוי עובר דרכי ב-Code Review, מתועד מדרישה ועד קוד ובדיקות, וללא נתוני אמת מחוץ לסביבה המאושרת.

אשמח להמשיך לשלב הבא יחד.
